# Pygame Snake

Game Snake sederhana yang dibuat dengan bahasa pemrograman Python dan library Pygame. Proyek game ini dirancang untuk pemula yang ingin belajar pemrograman menggunakan Python dan cara membuat game sederhana.

## Tentang Proyek

Game ini mendemonstrasikan konsep pemrograman fundamental seperti variabel, lists, tuple, conditional statement, loops, input keyboard, dan collision detection.

## Fitur

- Kendalikan Snake menggunakan tombol arrow di keyboard
- Pencatatan score untuk setiap makanan yang dimakan
- Snake semakin panjang seiring penambahan score dan banyaknya makanan yang dimakan
- Game Over jika terdeteksi tabrakan terhadap tubuh Snake atau dinding
- fitur mulai ulang (restart)

## Cara Download dan Main

1. Download `SnakeV1_0.zip` dari halaman [Releases](../../releases).
2. Extract file ZIP.
3. Buka folder yang di-extract.
4. Jalankan `Snake.exe`.

**Catatan:** 
- Pastikan file executable dan file/folder pendukungnya tetap dalam satu folder setelah di-extract.
- File executable ini dirancang untuk dapat berjalan tanpa memerlukan instalasi Python terpisah.
- Game hanya dapat dimainkan di komputer dengan sistem operasi Windows 10/11.

## Kontrol

| Tombol            | Aksi                                     |
| ----------------- | ---------------------------------------- |
| ↑ UP (ATAS)       | Menggerakkan Snake ke atas               |
| ← LEFT (KIRI)     | Menggerakkan Snake ke kiri               |
| → RIGHT (KANAN)   | Menggerakkan Snake ke kanan              |
| ↓ DOWN (BAWAH)    | Menggerakkan Snake ke bawah              |
| R                 | Restart Game                             |
| ESC               | Keluar dari Game                         |
